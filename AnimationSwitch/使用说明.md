# Windows 动画效果

无参数打开图形界面。带参数默认静默，无窗口、无控制台输出。

开启动画：AnimationSwitch.exe on
关闭动画：AnimationSwitch.exe off

on / off 均操作全部动画项，不区分大小写。仅支持这两个参数。
退出码：0 成功，1 操作失败，2 参数错误。

PowerShell 自动化并获取退出码：
```powershell
$p = Start-Process 'C:\Project\EricToolBox\AnimationSwitch\AnimationSwitch.exe' -ArgumentList 'on' -Wait -PassThru
$p.ExitCode
```

通过 SystemParametersInfoW 设置并逐项回读验证，由 Windows 保存、广播变化。不直接写注册表。在目标用户已登录的交互会话运行。多项调用非原子操作，失败可能已部分应用；RDP 重连可能再次覆盖设置。API 回读成功不保证所有应用或远程渲染路径均播放动画。
关闭时逐项关闭实际动画。UIEffects 包含其他 UI 效果，当前系统关闭该项后仍回读为开，因此仅作参考，不作为关闭动画的验证条件；开启时仍启用该项。

check：静默检测上述 API 状态，仅发现关闭项时执行开启操作；退出码 0 成功（含无需修改），1 操作失败。计划任务直接调用 AnimationSwitch.exe check，无需脚本。
