# my-toolbox

> A graveyard for tiny tools that didn’t deserve their own repo.

Random scripts, small utilities, and half-baked ideas.  
Some work. Some are load-bearing. Do not ask which.

## Contents

- `scripts/` — small scripts for small problems
- `tools/` — slightly more serious tools
- `experiments/` — questionable ideas, use at your own risk
- `archive/` — old stuff. Probably broken. Definitely emotional.

## Usage

Each tool lives in its own folder. Check the local README if it exists.  
If it doesn’t, good luck.

## Requirements

Depends on the tool. Usually Python, Node, shell, and hope.
